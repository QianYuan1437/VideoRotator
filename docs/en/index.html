VideoRotator

Rotate landscape videos 90° into portrait — metadata-only rotation with no cropping and no re-encoding. Completes in seconds with lossless quality. Ships with a Bilibili-style player and a rounded light-purple design language.

⬇ Download APK Source Code

Features

A complete loop from conversion to playback

🔄

Landscape → Portrait, Lossless

Uses setOrientationHint with MediaExtractor + MediaMuxer to change orientation metadata — no re-encoding, no cropping, no quality loss. Finishes in seconds. Clockwise or counter-clockwise 90°.

📺

Bilibili-style Player

Playback speed 0.5x–2.0x; drag the left edge for brightness, the right edge for volume; swipe vertically to seek; orientation lock against accidental touches; fullscreen toggle; double-tap play/pause; controls auto-hide after 3 seconds.

📁

Selectable Save Path

Save converted videos to the app-private folder, Movies, DCIM, Download, or any custom path. The browse tab lets you navigate video files by directory.

🎨

Theme & Background Colors

Eight theme swatches in two rows — tap one to see its name applied instantly. Background supports Light / Dark / Follow system. All choices are persisted and survive restarts.

🧭

Three-Tab Bottom Navigation

Video List, Conversion Config, Settings. The bottom navigation bar has 28dp rounded bottom corners with system gesture-bar insets, correctly adapting to rounded screen edges.

⚙️

Conversion Config Center

Output directory, rotation direction, keep-original and high-quality switches in one place. Progress bar during conversion, success feedback, and a one-tap “open containing folder”.

Build Locally

Prepare the environment

Install JDK 17 and the Android SDK, then set sdk.dir in local.properties.

Build the debug package

./gradlew assembleDebug — output at app/build/outputs/apk/debug/app-debug.apk.

Install & test

adb install -r app-debug.apk, or open the app directly on an emulator / device to test rotation and playback.
