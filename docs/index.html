VideoRotator 视频旋转助手

将横屏视频旋转 90° 转为竖屏 —— 纯元数据旋转、不裁切、不重编码，秒级完成、画质无损。内置 Bilibili 风格播放器与浅紫色圆润设计语言。

⬇ 下载 APK 查看源码

功能特性

从转换到播放的完整闭环

🔄

横屏转竖屏 · 无损旋转

基于 MediaExtractor + MediaMuxer 的 setOrientationHint 修改方向元数据，不重新编码：不裁切画面、不损失画质、转换在数秒内完成，支持顺时针 / 逆时针 90°。

📺

Bilibili 风格播放器

倍速播放 0.5x–2.0x；左侧上下滑动调节亮度、右侧调节音量；上下滑动拖动进度；视角锁定防误触；全屏切换；双击播放 / 暂停；控制栏 3 秒自动隐藏。

📁

保存路径可选

转换后的视频可保存到应用私有目录、Movies、DCIM、Download，或输入任意自定义路径；浏览页支持按目录浏览设备上的视频文件。

🎨

主题色 · 背景色可选

两行共 8 套主题色块，点选即显示配色名称并自动应用；背景支持浅色 / 深色 / 跟随系统三种模式，所有选择持久化保存，重启不丢失。

🧭

三 Tab 底部导航

视频列表、转换配置、相关设置三个标签页；底部导航栏底部 28dp 圆角并预留系统手势栏内边距，正确适配圆角屏幕底边。

⚙️

转换配置中心

输出目录、旋转方向、保留原始文件、高质量模式等开关集中管理；转换过程带进度条与成功反馈，一键打开所在文件夹。

本地构建

准备环境

安装 JDK 17 与 Android SDK，在 local.properties 中配置 sdk.dir。

构建 Debug 包

./gradlew assembleDebug，产物位于 app/build/outputs/apk/debug/app-debug.apk。

安装调试

adb install -r app-debug.apk，或直接在模拟器 / 真机上打开应用测试旋转与播放。
